# Phase 3: Supporting Foundations

## Goal

Build the Python, data, and mathematics foundation needed for later Machine Learning.

## 1. Python for Data Work

Learn the Python patterns commonly used when working with data.

## 2. NumPy

Understand:

- Arrays
- Shapes
- Indexing
- Vectorized operations
- Broadcasting

The focus is understanding why NumPy works differently from ordinary Python loops, not memorizing functions.

## 3. Pandas

Understand:

- DataFrames
- Series
- Indexing
- Filtering
- Grouping
- Missing values
- Basic data cleaning

## 4. Probability

Understand:

- Events
- Probability
- Conditional probability
- Distributions
- Expected value

## 5. Statistics

Understand:

- Mean
- Variance
- Standard deviation
- Correlation
- Distributions

## 6. Linear Algebra

Understand:

- Vectors
- Matrices
- Dot products
- Matrix multiplication
- Geometric meaning

## 7. Basic Calculus

Understand:

- Functions
- Derivatives
- Slopes
- Gradients
- Why gradients matter for optimization

## Practical Work

Use NumPy to perform array operations.

Use Pandas to load and clean a real dataset.

Calculate basic statistics.

Perform dot products and matrix multiplication manually and with NumPy.

Explain what a gradient represents.

## Project

Build an exploratory data analysis script using a real dataset.

## Exit Criteria

Given a small unfamiliar CSV file, load it, clean it, calculate basic statistics, create a simple visualization, and explain what the results mean.
