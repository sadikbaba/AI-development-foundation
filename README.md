# AI Learning

A practical foundation for understanding Artificial Intelligence before moving into Machine Learning, Deep Learning, and applied AI engineering.

## What I Will Learn

### Phase 1: AI Fundamentals

Understand what AI is, how intelligent agents work, search, heuristics, planning, decision making, reasoning, knowledge representation, and the basic idea of reinforcement learning.

### Phase 2: AI Problem Solving

Learn how to turn a real problem into states, actions, goals, constraints, and a search space that an AI system can work with.

### Phase 3: Supporting Foundations

Build the Python, NumPy, Pandas, probability, statistics, linear algebra, and basic calculus foundations needed for later Machine Learning.

## Projects

The concepts are reinforced through small Python projects, including a rule-based agent, a state-space search solver, and exploratory data analysis.

## Goal

The goal is not to memorize AI terms or blindly use frameworks. It is to understand the ideas well enough to explain them, implement simple systems, and build a strong foundation for Machine Learning and later AI engineering.
